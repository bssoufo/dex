  <action>
    Create `backend/src/etl/scrape/parsers/utils.py` with parsing functions that handle the variety of formats found across manufacturer sites (per research: decimal inches, feet-inches, metric, with/without unit labels).

    Functions to implement:

    1. `parse_dimension_inches(text: str) -> float | None`:
       Handles: "89.0", "89", "7'10\"", "7'-10\"", "2.39m", "37.5 inches", "37.5 in", "37.5\"", "37 1/2".
       Returns float inches or None if unparseable.
       Strip commas, whitespace. Try each format in order:
       - Feet-inches regex: `(\d+)['\u2032]-?\s*(\d+(?:\.\d+)?)[\"″\u2033]?`
       - Meters: `(\d+\.?\d*)\s*m\b` -> multiply by 39.3701
       - Centimeters: `(\d+\.?\d*)\s*cm\b` -> multiply by 0.393701
       - Fractional: `(\d+)\s+(\d+)/(\d+)` -> whole + fraction
       - Plain number with optional unit label: `(\d+\.?\d*)\s*(inches|in|"|'')?`

    2. `parse_weight_lbs(text: str) -> float | None`:
       Handles: "825 lbs", "825", "825 lbs.", "825 pounds", "1,250 lbs".
       Strip commas, extract first number, return float or None.

    3. `parse_gallons(text: str) -> float | None`:
       Handles: "270 gallons", "270 gal", "270 gal.", "270", "270-290 gallons" (take first number).
       Strip commas, extract first number, return float or None.

    4. `parse_int(text: str) -> int | None`:
       Handles: "60", "60 jets", "7 seats". Extract first integer. Return int or None.

    5. `parse_float(text: str) -> float | None`:
       Handles: "2.5 HP", "130.0", "5.5". Extract first float. Return float or None.

    6. `clean_text(text: str) -> str`:
       Strip whitespace, normalize unicode whitespace chars, collapse multiple spaces.

    Each function should:
    - Accept empty/None input gracefully (return None)
    - Use `re` for parsing
    - Not raise exceptions -- always return None on failure
    - Include a docstring with examples of handled formats
  </action>
