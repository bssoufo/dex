  <files>backend/src/etl/scrape/merger.py</files>
  <action>
    Create `backend/src/etl/scrape/merger.py` with the merge logic that supplements existing JSON data with scraped web data.

    CRITICAL RULE: Web data ONLY fills null/None/0 fields. NEVER overwrite a non-null value from PDF extraction. PDF is the authoritative source.

    Implement `merge_scraped_into_model(json_path: Path, scraped: ScrapedSpecs) -> dict`:

    1. Read the existing JSON file at `json_path` using `json.load()`.

    2. Define field mappings from ScrapedSpecs fields to JSON paths:
       - `scraped.length_inches` -> `existing["dimensions"]["length_inches"]`
       - `scraped.width_inches` -> `existing["dimensions"]["width_inches"]`
       - `scraped.height_inches` -> `existing["dimensions"]["height_inches"]`
       - `scraped.dry_weight_lbs` -> `existing["dimensions"]["dry_weight_lbs"]`
       - `scraped.filled_weight_lbs` -> `existing["dimensions"]["filled_weight_lbs"]`
       - `scraped.water_capacity_gallons` -> `existing["dimensions"]["water_capacity_gallons"]`
       - `scraped.seating_capacity` -> `existing["seating_capacity"]`
       - `scraped.total_jet_count` -> `existing["jets"]["total_jet_count"]` (only if jets section exists)
       - `scraped.filtration_area_sqft` -> `existing["filters"]["filters"][0]["filtration_area_sqft"]` (only if filters section exists and has at least one filter)
       - `scraped.heater_wattage` -> `existing["heater"]["wattage"]` (only if heater section exists)
       - `scraped.electrical_volts` -> `existing["voltage"]`
       - `scraped.electrical_amps` -> `existing["amperage"]`
       - `scraped.diverter_valves` -> `existing["jet_pumps"]["diverter_valves"]` (only if jet_pumps section exists)

    3. For each mapping:
       - If scraped value is None: skip (nothing to merge).
       - If existing value is not None AND not 0 AND not 0.0: skip (preserve PDF data). Log: "KEPT existing {field}={existing_value} (web had {scraped_value})".
       - If existing value is None or 0 or 0.0: update with scraped value. Log: "FILLED {field}={scraped_value} (was {existing_value})".

    4. Track all updated fields in a list for the return report.

    5. If ANY fields were updated, append a SourceReference to `existing["source_documents"]`:
       ```python
       {
           "source_type": "website",
           "url": scraped.source_url,
           "document_name": None,
           "page_number": None,
           "section": None,
           "accessed_date": date.today().isoformat(),
           "verified_by": None,
           "verified_date": None,
       }
       ```

    6. Write the updated JSON back to `json_path` with `json.dump(data, f, indent=2)` and a trailing newline.

    7. Return a dict with keys:
       - `model_name`: str
       - `fields_updated`: list[str] (field paths that were filled)
       - `fields_kept`: list[str] (field paths where existing data was preserved)
       - `fields_missing`: list[str] (field paths where both existing and scraped were null)
       - `source_url`: str

    Also implement a helper `resolve_json_path(manufacturer: str, series: str, model_name: str, year: int = 2026) -> Path`:
    - Uses the same slugify logic as the existing writer: `DATA_OUTPUT_DIR / manufacturer / slugify(series) / f"{slugify(model_name)}-{year}.json"`
    - Import `DATA_OUTPUT_DIR` from `backend/src/etl/config.py`
    - The slugify function should match the one in `backend/src/etl/output/writer.py` (lowercase, replace non-alphanumeric with hyphens).
  </action>

    Create `backend/src/etl/scrape/pipeline.py` as the orchestrator that ties together fetcher, parsers, and merger.

    Implement:

    1. `PARSERS` registry dict mapping manufacturer key to parser instance:
       ```python
       PARSERS = {
           "sundance": SundanceParser(),
           "hotspring": HotSpringParser(),
           "bullfrog": BullfrogParser(),
       }
       ```

    2. `MANUFACTURER_META` dict mapping manufacturer key to series name:
       ```python
       MANUFACTURER_META = {
           "sundance": "880 Series",
           "hotspring": "Highlife Collection",
           "bullfrog": "M Series",
       }
       ```

    3. `scrape_model(manufacturer: str, model_entry: dict, fetcher: PageFetcher) -> dict | None`:
       - `model_entry` has keys: `model_name`, `url`, `alt_url` (from SCRAPE_URLS config).
       - Get the appropriate delay from `get_delay_for_url(model_entry["url"])`.
       - Fetch the page using `fetcher.fetch_with_fallback(url, alt_url, delay)`.
       - If fetch fails (exception), log error and return None.
       - Parse the HTML using the appropriate parser: `PARSERS[manufacturer].parse_model_page(html, model_name)`.
       - Set `scraped.source_url` to the URL that was actually fetched.
       - Resolve the JSON path using `resolve_json_path(manufacturer, series, model_name)`.
       - If JSON file does not exist, log warning and return None (no file to merge into).
       - Call `merge_scraped_into_model(json_path, scraped)` and return the result dict.

    4. `run_scrape_pipeline(manufacturers: list[str] | None = None) -> dict`:
       - If manufacturers is None, process all three.
       - Create a single PageFetcher instance (context manager).
       - For each manufacturer, iterate over its models in SCRAPE_URLS.
       - Call `scrape_model()` for each.
       - Collect results into a report dict:
         ```python
         {
             "total_models": 19,
             "models_scraped": N,
             "models_failed": M,
             "total_fields_updated": X,
             "by_manufacturer": {
                 "sundance": {"scraped": 7, "failed": 0, "fields_updated": [...]},
                 ...
             },
             "details": [
                 {"manufacturer": "sundance", "model": "Aspen", "fields_updated": [...], "fields_kept": [...]},
                 ...
             ],
         }
         ```
       - Print a human-readable summary at the end showing:
         - Per-manufacturer success/failure counts
         - Total fields updated across all models
         - Any models that failed (with error reason)
         - Fields that were updated vs kept vs still missing per model

    5. CLI entry point at bottom of file:
       ```python
       if __name__ == "__main__":
           import sys
           mfrs = sys.argv[1:] if len(sys.argv) > 1 else None
           run_scrape_pipeline(mfrs)
       ```
       Invocation: `uv run python -m src.etl.scrape.pipeline` (all) or `uv run python -m src.etl.scrape.pipeline sundance` (one manufacturer).

    6. **EXECUTE THE PIPELINE** against all 19 models:
       ```
       cd /c/dvl/IA/spaparts/dex/backend
       uv run python -m src.etl.scrape.pipeline
       ```
       This will take ~3-4 minutes due to rate limiting (especially 10s delay for Bullfrog's 4 pages).

       - Check that Sundance Aspen now has non-zero dimensions (was 0.0/0.0/0.0 before).

       - Check that no source_documents entries were lost or corrupted.
       - Check that existing non-null values (like Aspen's jet count of 60, amperage of 39) are unchanged.

       - Print a clear summary of any models that failed scraping.
