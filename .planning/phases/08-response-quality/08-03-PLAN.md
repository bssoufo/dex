  <action>
Add a new test group "Test Group 7: Response Quality" to test_agent_integration.py. Follow the existing pattern: async tests with `agent_and_client` fixture, using the `_ask()` helper, marked with `@pytest.mark.timeout(60)`.

Add these tests:

1. `test_response_includes_source_attribution` -- Ask "What is the heater spec for the Sundance Cameo?" Assert the answer contains "Source:" or "source:" (case-insensitive regex `r"[Ss]ource[s]?:"`). This validates RESP-01: every response cites its data source.

2. `test_response_scannable_format` -- Ask "What jet pumps does the Sundance Aspen have?" Assert the answer contains at least one bullet point character (`-` or `*` at start of a line, or contains `\n- ` or `\n* `). Also assert the answer has 3+ lines (not a single prose paragraph). This validates RESP-05: clean scannable format with specs as bulleted lists.

3. `test_response_includes_cross_references` -- Ask "What heater does the Sundance Aspen use?" (Sundance heater is shared across ALL 7 models). Assert the answer contains at least one other Sundance model name (check for any of: "Altamar", "Cameo", "Optima", "Marin", "Capris", "Vistamar") OR contains the phrase "shared across all" or "also used in". This validates RESP-04: cross-reference information appears.

4. `test_response_bold_formatting` -- Ask "What filter does the Sundance Cameo use?" Assert the answer contains bold markdown markers (`**`). This validates RESP-05: part numbers and key values are prominently displayed with emphasis.

5. `test_response_quality_no_regression` -- Ask "What pump does the Hot Spring Grandee use?" Assert the answer still contains domain keywords ("pump", "hp" or "speed"), answer length > 20, and elapsed < 45s. This is a sanity check that the enhanced prompt does not degrade accuracy or performance.

Important considerations:
- These tests hit the real Gemini API, so mark with the module-level `pytestmark` (already includes `integration` and `flaky(reruns=2)`).
- LLM responses are non-deterministic. Tests should use flexible assertions (checking for presence of patterns, not exact strings).
- For the cross-reference test, the LLM may or may not call find_cross_references on every query. The test should pass if either explicit model names appear OR a "shared across" phrase appears.
- Keep timeout at 60s per test (same as existing category tests).

Update the module docstring test group list to include "7. Response quality (5) -- source attribution, formatting, cross-references".
