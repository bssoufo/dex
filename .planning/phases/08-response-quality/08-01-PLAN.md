  <action>
Add a `find_cross_references()` function to `data_store.py` that:

1. Accepts `manufacturer: str`, `model_name: str`, `category: str`, and optional `exclude_keys: tuple[str, ...] = ("part_number", "shared_with_series", "model_name")`.
2. Loads the target model via `get_model(manufacturer, model_name)`. Returns empty list if model not found.
3. Gets the category data via `getattr(target, category, None)`. Returns empty list if category data is None.
4. Creates a comparison signature by calling `target_data.model_dump()` and removing `exclude_keys` from the dict.
5. Iterates all models in the store from the SAME manufacturer (case-insensitive on manufacturer key).
6. Skips the target model itself (case-insensitive model_name comparison).
7. For each other model, gets the same category data, creates the same comparison signature (model_dump + remove exclude_keys).
8. If signatures match (dict equality), adds the model name to the matches list.
9. Returns `sorted(matches)`.

The exclude_keys removes part_number (mostly null, not meaningful for comparison), shared_with_series (metadata, not spec), and model_name (would always differ). This ensures we compare actual component specs like HP, wattage, count, etc.

The comparison uses Pydantic's model_dump() which produces consistent dict representations for equality comparison.
