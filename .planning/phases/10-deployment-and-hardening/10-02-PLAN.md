<task type="auto">
  <name>Task 1: Create Railway config and deploy</name>
  <files>
    railway.json
  </files>
  <action>
    Create railway.json at project root:
    ```json
    {
      "$schema": "https://railway.com/railway.schema.json",
      "build": {
        "builder": "DOCKERFILE",
        "dockerfilePath": "Dockerfile"
      },
      "deploy": {
        "startCommand": "uvicorn backend.src.api.app:app --host 0.0.0.0 --port ${PORT:-8000}",
        "healthcheckPath": "/health",
        "healthcheckTimeout": 120,
        "restartPolicyType": "ON_FAILURE",
        "restartPolicyMaxRetries": 3
      }
    }
    ```

    Then deploy to Railway using the CLI. If `railway` CLI is not installed, install it:
    ```
    npm install -g @railway/cli
    ```

    Attempt to log in with:
    ```
    railway login
    ```
    If login fails (requires browser), this will become a checkpoint. If it succeeds, continue.

    Create a new Railway project:
    ```
    railway init
    ```
    Choose a project name like "dex" when prompted.

    Set environment variables:
    ```
    railway variables set GEMINI_API_KEY=<value from backend/.env>
    railway variables set ENVIRONMENT=production
    ```
    Read the GEMINI_API_KEY from backend/.env (do NOT hardcode it in the plan -- read it at execution time with `grep GEMINI_API_KEY backend/.env | cut -d= -f2`).

    Deploy:
    ```
    railway up
    ```

    After deploy completes, get the deployment URL:
    ```
    railway domain
    ```
    If no domain is assigned, generate one:
    ```
    railway domain
    ```
    Railway auto-assigns a *.up.railway.app domain.

    Run smoke tests against the live URL:
    ```
    curl -s https://<railway-domain>/health
    curl -s https://<railway-domain>/ | head -10
    ```

    Verify /health returns `{"status":"ok","agent_ready":true}` and / returns HTML.
  </action>
  <verify>
    - `curl https://<railway-domain>/health` returns `{"status":"ok","agent_ready":true}`
    - `curl https://<railway-domain>/` returns HTML containing the React app
    - `curl -X POST https://<railway-domain>/query -H "Content-Type: application/json" -d '{"question":"What pump does the Sundance Aspen use?"}'` returns a JSON response with an answer (not an error)
  </verify>
  <done>
    - railway.json exists with Dockerfile builder and health check config
    - Railway project created with GEMINI_API_KEY and ENVIRONMENT=production set
    - Deployment succeeds and is accessible via HTTPS
    - /health endpoint returns agent_ready:true
    - Root URL serves the React chat interface
    - /query endpoint returns a valid answer
  </done>
