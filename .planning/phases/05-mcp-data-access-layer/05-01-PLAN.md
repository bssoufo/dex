<objective>
Build the MCP data access layer: install FastMCP, create the in-memory data store over 19 verified JSON files, and implement 3 strongly-typed MCP tools (get_spec_category, get_model_overview, list_models) as the deterministic gateway to spa specification data.

Purpose: This is the bridge between raw data (Phases 1-4) and the agent (Phase 6). All spec lookups go through these tools -- no direct file access, no RAG, no LLM logic in the data layer.
Output: A runnable FastMCP server with 3 tools that accept enum-constrained parameters and return structured JSON responses.
</objective>

  <name>Task 2: Build MCP server with 3 tools and entry point</name>
  <files>

  <action>
    1. Create `backend/src/mcp/server.py` with a `FastMCP` server instance and 3 tool functions:

       **Server instance:**
       ```python
       mcp = FastMCP(
           name="DexDataServer",
           instructions="Dex data server provides deterministic lookup of spa technical specifications. Use get_spec_category for specific data, get_model_overview for model summaries, and list_models for discovery.",
       )
       ```

       **Tool 1: `get_spec_category(manufacturer: Manufacturer, model_name: ModelName, category: SpecCategory) -> dict`**
       - Use `Annotated[ModelName, Field(description="Spa model name")]` and `Annotated[SpecCategory, Field(description="Spec category to retrieve")]` for parameter descriptions.
       - Call `get_model(manufacturer.value, model_name)`. If None, return `{"success": False, "message": "Model '{model_name}' not found for manufacturer '{manufacturer.value}'"}`.
       - Get category data via `getattr(model, category.value, None)`. If None, return success=True with data=None and an explanatory message.
       - If data exists, serialize with `.model_dump()` (NOT `.model_dump(exclude_none=True)` -- preserve null fields so the agent sees what's missing).
       - Extract not_available_fields for this category from `model.data_quality.not_available_fields` by filtering for fields starting with `{category.value}.` and stripping that prefix.
       - Include `source_documents` from the model (serialize each with `.model_dump()`).
       - Return: `{"success": True, "manufacturer": ..., "model_name": ..., "category": ..., "data": ..., "not_available_fields": [...] or None, "source_documents": [...]}`.
       - Docstring must explain purpose clearly since LLM agents use it for tool selection.

       **Tool 2: `get_model_overview(manufacturer: Manufacturer, model_name: ModelName) -> dict`**
       - Look up model. If None, return not-found response.
       - Iterate over all `SpecCategory` values, check which have data via `getattr(model, cat.value)`.
       - Return: `{"success": True, "manufacturer": ..., "series": ..., "model_name": ..., "year": ..., "seating_capacity": ..., "dimensions": model.dimensions.model_dump(), "voltage": ..., "amperage": ..., "categories_available": [...], "categories_missing": [...]}`.

       **Tool 3: `list_models(manufacturer: Manufacturer | None = None) -> dict`**
       - Use `Annotated[Manufacturer | None, Field(description="Filter by manufacturer (optional)")]` with default None.
       - Iterate `get_store().values()`, filter by manufacturer if provided.
       - Return sorted list by (manufacturer, model_name): `{"success": True, "count": N, "models": [{"manufacturer": ..., "series": ..., "model_name": ..., "year": ..., "seating_capacity": ...}, ...]}`.

       **Import from correct locations:**
       - `from backend.src.mcp.data_store import get_model, get_store`
       - `from backend.src.mcp.enums import ModelName, SpecCategory`
       - `from backend.src.schema.enums import Manufacturer`

    2. Create `backend/src/mcp/__main__.py`:
       ```python
       """Run the Dex MCP data server."""
       from backend.src.mcp.server import mcp

       if __name__ == "__main__":
           mcp.run(transport="stdio")
       ```
