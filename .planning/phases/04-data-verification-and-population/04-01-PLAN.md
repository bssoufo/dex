  2. Create `backend/src/etl/verify/checks.py` with these verification functions:

  **Data structures:**
  ```python
  @dataclass
  class Anomaly:
      model_name: str
      category: str
      check_name: str
      severity: str  # "error" | "warning" | "info"
      message: str

  @dataclass
  class VerificationResult:
      model_name: str
      manufacturer: str
      checks_passed: int = 0
      checks_failed: int = 0
      anomalies: list[Anomaly] = field(default_factory=list)
  ```

  **Check functions (each takes a SpaModel and returns list[Anomaly]):**

  a) `check_voltage_consistency(model: SpaModel) -> list[Anomaly]`
     - Compare top-level voltage, spa_pak.voltage, heater.voltage
     - If any differ, return anomaly with severity="error"
     - Expected to flag: Jetsetter LX (spa_pak 115V vs 230V), Prodigy (spa_pak 115V vs 230V)

  b) `check_cover_dimensions(model: SpaModel) -> list[Anomaly]`
     - If cover has length/width, compare against dimensions.length/width
     - If cover length matches spa width AND cover width matches spa length (within 1 inch), flag as "dimensions appear swapped" with severity="error"
     - Expected to flag: M6, M9

  c) `check_jet_counts(model: SpaModel) -> list[Anomaly]`
     - If jets.total_jet_count exists and jets.jets_by_type is non-empty, sum the quantities in jets_by_type
     - If total != sum, flag with severity="warning" (may be legitimate counting differences)
     - Include both values in the message
     - Expected to flag: Envoy, Grandee, Jetsetter, Altamar, Aspen, Cameo

  d) `check_missing_categories(model: SpaModel) -> list[Anomaly]`
     - Check all 10 category fields on SpaModel
     - If a category is None, flag as severity="warning" with "category entirely missing"
     - If a category exists but ALL its meaningful fields are None (exclude shared_with_series, exclude list fields that are empty), flag as severity="info" with "category present but all fields null"
     - Expected NULL: Marin filters, Jetsetter LX lighting
     - Expected EMPTY: M6/M7/M8/M9 heater, M8/M9 spa_pak

  e) `check_source_tracking(model: SpaModel) -> list[Anomaly]`
     - If source_documents is empty, flag as severity="error"
     - If all source_documents have verified_by=None, flag as severity="info" (expected pre-verification)

  f) `check_ranges(model: SpaModel) -> list[Anomaly]`
     - Reuse the plausible ranges from etl/transform/validators.py conceptually (define ranges inline, do NOT import from validators.py since that module expects CategoryExtraction not SpaModel)
     - Check: seating_capacity (2-10), dimensions (40-150 L/W, 20-60 H), horsepower (0.5-10), jet_count (5-200), wattage (1000-6000)

  **Orchestrator:**
  ```python
  def run_all_checks(model: SpaModel) -> VerificationResult:
      """Run all verification checks against a single model."""
      result = VerificationResult(model_name=model.model_name, manufacturer=model.manufacturer.value)
      all_checks = [
          check_voltage_consistency,
          check_cover_dimensions,
          check_jet_counts,
          check_missing_categories,
          check_source_tracking,
          check_ranges,
      ]
      for check_fn in all_checks:
          anomalies = check_fn(model)
          if anomalies:
              result.checks_failed += 1
              result.anomalies.extend(anomalies)
          else:
              result.checks_passed += 1
      return result
  ```

  **Loader utility (in same file or a small helper):**
  ```python
  def load_all_models() -> list[SpaModel]:
      """Load and validate all 19 JSON data files."""
      import json
      from pathlib import Path
      data_dir = Path(__file__).resolve().parents[3] / "data"
      models = []
      for f in sorted(data_dir.rglob("*.json")):
          data = json.loads(f.read_text())
          models.append(SpaModel.model_validate(data))
      return models
  ```

  IMPORTANT: The `check_missing_categories` function must correctly handle the `_is_all_null` check. For category models that contain list fields (like JetPumpSpecs.pumps, FilterSpecs.filters, etc.), an empty list counts as "empty." For boolean fields like `shared_with_series` and `is_dedicated`, skip them in the nullity check (they have defaults). Focus on string, numeric, and PartReference fields.
