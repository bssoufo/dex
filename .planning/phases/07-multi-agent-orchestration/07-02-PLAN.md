Add conversation session support to the FastAPI layer for multi-turn queries, and wire the deterministic validator into the /query endpoint.

Purpose: The API must accept an optional conversation_id from the client, pass it as thread_id to the LangGraph checkpointer, and return it in every response so the client can continue the conversation.    - Import `uuid4` from uuid at top of file (will be used by app.py but good to have the import available).

2. Update `backend/src/api/app.py`:
   - Update lifespan to use the new multi-agent graph:
     ```python
     from backend.src.agent.graph import create_multi_agent
     from backend.src.agent.validator import validate_response

     _agent = None
     _mcp_client = None

     @asynccontextmanager
     async def lifespan(app: FastAPI):
         global _agent, _mcp_client

         agent, client = await create_multi_agent()
         _agent = agent
         _mcp_client = client

         yield

         _agent = None
         _mcp_client = None
     ```
   - Remove the old imports of `_create_mcp_client`, `_create_model`, `SYSTEM_PROMPT`, `create_react_agent` from lifespan.

   - Update the `/query` endpoint:
     - Generate conversation_id if not provided: `conv_id = request.conversation_id or str(uuid4())` (import uuid4 from uuid).
     - Pass thread_id to agent: `config = {"configurable": {"thread_id": conv_id}}`.
     - Invoke with config: `result = await _agent.ainvoke({"messages": [{"role": "user", "content": request.question}]}, config=config)`.
     - Keep existing Gemini content normalization logic for extracting answer_text.
     - Keep existing tool_call_info extraction logic.
     - **CRITICAL -- Wire the validator here:** After getting the result from agent.ainvoke(), call `warnings = validate_response(result)`. This is where the deterministic validator from Plan 07-01 actually executes during real queries. The validate_response function accepts the full result dict (which has a "messages" key) and returns a list[str] of warning strings (empty list means clean).
     - Convert empty warnings list to None for cleaner JSON: `validation_warnings = warnings if warnings else None`.
     - Return `QueryResponse(answer=answer_text, conversation_id=conv_id, tool_calls=tool_call_info, validation_warnings=validation_warnings)`.

   - Keep the `/health` endpoint unchanged.
