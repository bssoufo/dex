Build all React components for the chat interface. Follow the research code examples closely but adapt for production quality.

1. **`src/hooks/useChat.ts`** -- Custom hook managing chat state and SSE connection:
   - State: `messages: Message[]`, `isLoading: boolean`
   - Refs: `conversationId: string | null`, `abortController: AbortController | null`
   - `sendMessage(question: string)` function (useCallback):
     a. Add user message to state (with `crypto.randomUUID()` id, role "user").
     b. Add empty assistant message (role "assistant", content "", isStreaming true).
     c. Set isLoading true.
     d. Create new AbortController.
     e. Call `streamQuery()` from api.ts with callbacks:
        - `onMetadata`: Store conversation_id in ref.
        - `onToken`: Append `data.content` to last message's content. Use functional state update: `setMessages(prev => ...)` creating new array and new message object (never mutate -- research pitfall #5).
        - `onDone`: Set last message's `isStreaming` to false. Set `isLoading` false.
        - `onValidation`: If warnings exist, append them as a system note to the last message content (e.g., add `\n\n---\n_Validation: {warning}_` for each warning). Or store in a separate state if preferred. Keep it simple -- just log warnings to console for v1.
        - `onError`: Set `isLoading` false. Update last assistant message content to an error string like "Sorry, something went wrong. Please try again."
     f. Pass `abortController.signal` for cleanup.
   - `resetConversation()` function: Clears messages, sets conversationId to null. Aborts any in-flight request.
   - Return: `{ messages, isLoading, sendMessage, resetConversation }`

2. **`src/components/MarkdownRenderer.tsx`** -- Wrapper around react-markdown with GFM:
   - Props: `{ content: string }`
   - Uses `ReactMarkdown` with `remarkPlugins={[remarkGfm]}`.
   - Custom component overrides for table styling (Tailwind classes):
     - `table`: Wrap in `overflow-x-auto my-2`, table gets `min-w-full border-collapse text-sm`.
     - `thead`: `bg-gray-100` background.
     - `th`: `border border-gray-300 px-3 py-1.5 text-left font-semibold text-gray-700`.
     - `td`: `border border-gray-300 px-3 py-1.5`.
     - `strong`: `font-bold text-gray-900` (part numbers stand out).
     - `p`: `mb-2 last:mb-0` (paragraph spacing within responses).
     - `ul` / `ol`: Proper list styling with `list-disc ml-4 mb-2` / `list-decimal ml-4 mb-2`.
     - `h3` / `h4`: Section headings with appropriate sizing and margin.
   - Export as named export.

3. **`src/components/MessageBubble.tsx`** -- Renders a single message:
   - Props: `{ message: Message }`
   - User messages: Right-aligned, blue background (`bg-blue-600 text-white`), plain text (no markdown).
   - Assistant messages: Left-aligned, light gray background (`bg-gray-50 border border-gray-200`), rendered via `<MarkdownRenderer content={message.content} />`.
   - Streaming indicator: When `message.isStreaming` is true and content is empty, show a pulsing dot indicator (3 dots with staggered animation using Tailwind `animate-pulse`). When content exists but still streaming, show a blinking cursor block after the content.
   - Max width 80% (`max-w-[80%]`) so messages don't span full width.

4. **`src/components/ChatInput.tsx`** -- Text input with submit:
   - Props: `{ onSubmit: (message: string) => void, disabled: boolean }`
   - Controlled input with local state.
   - Form with `onSubmit` handler: trims input, rejects empty, calls `onSubmit`, clears input.
   - Submit on Enter key (form default behavior). Shift+Enter NOT needed (single-line input).
   - Submit button: Blue, disabled when empty or when `disabled` prop is true.
   - Placeholder text: "Ask about spa specs, parts, or models..."
   - Styling: Bottom-fixed strip with border-top, white background, `px-6 py-3`.

5. **`src/components/ChatContainer.tsx`** -- Main chat layout:
   - Uses `useChat()` hook.
   - Layout: `flex flex-col h-screen max-w-4xl mx-auto` (full height, centered, max width).
   - Header: Top bar with "Dex" title and "Spa Parts Technical Assistant" subtitle. Include a "New Chat" button (calls `resetConversation`) styled as a subtle text button in the header.
   - Messages area: `flex-1 overflow-y-auto px-6 py-4 space-y-4`. Maps over `messages` rendering `<MessageBubble />` for each. Uses `message.id` as the React key.
   - Auto-scroll: `useRef` on a div at the bottom of the messages list. `useEffect` triggers `scrollIntoView({ behavior: "smooth" })` whenever `messages` changes.
   - Empty state: When messages is empty, show a centered welcome message: "What would you like to know about spa specifications?" in muted text.
   - Input: `<ChatInput onSubmit={sendMessage} disabled={isLoading} />` at the bottom.
   - Background: `bg-white` or `bg-gray-50` for the messages area to keep it clean.
