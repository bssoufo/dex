  <action>
Add CORS middleware to the FastAPI app so the frontend can connect even without the Vite dev proxy (needed for Phase 10 deployment and for `npm run preview` testing).

Add to `app.py` after `app = FastAPI(...)`:

```python
from fastapi.middleware.cors import CORSMiddleware

app.add_middleware(
    CORSMiddleware,
    allow_origins=[
        "http://localhost:5173",   # Vite dev server
        "http://localhost:4173",   # Vite preview server
    ],
    allow_credentials=True,
    allow_methods=["*"],
    allow_headers=["*"],
)
```

Then start both backend and frontend to test the connection:

1. Start backend: `cd backend && uvicorn backend.src.api.app:app --host 0.0.0.0 --port 8000` (from project root, or set PYTHONPATH appropriately).
2. Start frontend: `cd frontend && npm run dev`.
3. Open `http://localhost:5173` in a browser.

If there are any connection issues (proxy not working, SSE events not parsing, etc.), debug and fix them. Common issues:
- Vite proxy not stripping `/api` prefix correctly -- verify the rewrite rule.
- SSE content-type header not being set -- verify `media_type="text/event-stream"`.
- CORS preflight failing -- verify the middleware is applied before routes.
- Gemini API key not loaded -- verify `backend/.env` has `GEMINI_API_KEY`.

Test the following queries manually to verify end-to-end:
- "What pump does the Sundance Aspen use?" (should return spec data with source attribution)
- "What about the filter for that model?" (follow-up -- should maintain context)
- Click "New Chat" then ask "List all available models" (should start fresh conversation)
