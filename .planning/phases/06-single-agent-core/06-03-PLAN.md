**Helper function:**
```python
async def _ask(agent, question: str) -> tuple[str, float]:
    start = time.monotonic()
    result = await agent.ainvoke(
        {"messages": [{"role": "user", "content": question}]}
    )
    elapsed = time.monotonic() - start
    return result["messages"][-1].content, elapsed
```

**Test Group 2: Anti-hallucination (2 tests)**

- test_missing_part_number_flagged: Ask "What is the part number for the Sundance Aspen jet pump?" -- most part_numbers are null. Assert answer contains one of: "not available", "no part number", "unavailable", "not yet"
- test_null_field_not_echoed: Ask about a known null field. Assert the word "null" does NOT appear verbatim in the answer (agent should humanize it).

**Test Group 3: Out-of-scope (2 tests)**

- test_out_of_scope_model: Ask "What pump does the Jacuzzi J-335 use?" Assert answer contains indication it is out of scope (one of: "don't have", "not available", "only have", "19", "not in").
- test_out_of_scope_pricing: Ask "How much does the Sundance Aspen cost?" Assert answer contains one of: "pricing", "technical", "specialize", "cannot", "don't provide".

**Test Group 4: Performance (1 test)**

- test_simple_query_under_threshold: Ask "What is the heater wattage for the Hot Spring Grandee?" Assert response completes in under 10 seconds (use 10s threshold for CI reliability -- the 3-second target is aspirational and depends on network/API conditions; log actual time for manual review).

**IMPORTANT NOTES for implementation:**
- Use `time.monotonic()` for timing (not time.time())
- All string matching must be case-insensitive (`.lower()`)
- Do NOT assert exact values -- LLM responses vary in wording. Assert presence of domain-relevant keywords.
- If Gemini rate limits hit (429), the test should fail gracefully with a clear message, not hang. Consider adding a timeout to the agent.ainvoke call.
- Set PYTHONPATH=.. when running from backend/ directory
