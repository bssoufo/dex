         - `analyze_pdf_structure(pdf_path: Path) -> dict`: Opens PDF with pdfplumber, iterates all pages, returns dict with `total_pages`, and per-page info: `page_number`, `has_tables`, `table_count`, `text_preview` (first 300 chars of extracted text).          - `extract_tables(pdf_path: Path, page_numbers: list[int]) -> list[dict]`: Extracts tables from specific pages using pdfplumber with settings `vertical_strategy="lines", horizontal_strategy="lines", snap_tolerance=3`. Returns list of dicts with `page` and `data` (list of rows) keys.

       - `templates/__init__.py` -- empty
       - `templates/base.py` -- ManufacturerTemplate ABC:
         ```python
         from abc import ABC, abstractmethod

         class ManufacturerTemplate(ABC):
             @property
             @abstractmethod
             def manufacturer_name(self) -> str: ...

             @property
             @abstractmethod
             def series_name(self) -> str: ...

             @property
             @abstractmethod
             def models(self) -> list[str]: ...

             @abstractmethod
             def get_extraction_prompt(self, model_name: str, spec_category: str) -> str: ...

             @abstractmethod
             def get_page_hints(self, spec_category: str) -> str: ...
         ```
