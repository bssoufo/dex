  <action>
    1. Create the directory structure: `backend/src/schema/` with `__init__.py` files for both `src` and `schema` packages.

    2. Create `backend/src/schema/enums.py` with the following StrEnum classes:
       - `Manufacturer`: sundance, hotspring, bullfrog
       - `PumpSpeed`: 1-speed, 2-speed, variable
       - `JetSystemType`: fixed, modular_jetpak
       Use `from enum import StrEnum`. Do NOT use Literal types for these -- they are enums because the values are shared across multiple fields and models.

    3. Create `backend/src/schema/parts.py` with three Pydantic BaseModel classes:
       - `PartReference`: part_number (str, required), description (str | None = None), supersedes (str | None = None), superseded_by (str | None = None), fits_models (list[str], default_factory=list), fits_years (str | None = None), notes (str | None = None). Add Field(description=...) for part_number explaining it is the primary identifier.
       - `SourceReference`: source_type (Literal["pdf", "website", "manual_entry"]), url (str | None = None), document_name (str | None = None), page_number (int | None = None), section (str | None = None), accessed_date (str | None = None), verified_by (str | None = None), verified_date (str | None = None).
       - `DimensionsSpec`: length_inches (float), width_inches (float), height_inches (float), dry_weight_lbs (float | None = None), filled_weight_lbs (float | None = None), water_capacity_gallons (float | None = None).

    4. Create `backend/src/schema/__init__.py` that imports and re-exports the enums, PartReference, SourceReference, and DimensionsSpec (the public API of the shared models). Leave SpaModel import as a placeholder comment -- it will be added in Task 2.

    All models must use Pydantic v2 API exclusively:
    - `from pydantic import BaseModel, Field, ConfigDict`
    - `T | None = None` for optional fields (NOT `Optional[T]`)
    - `from __future__ import annotations` at the top of each file for forward reference support
  </action>

    Expected: Enums print ['sundance', 'hotspring', 'bullfrog'], PartReference instantiates with supersession data, prints OK.
  </verify>

    The 10 category models (in order of definition):

    1. **JetPumpSpec** (single pump): position (int, Field(ge=1)), model_name (str | None), horsepower_continuous (float), horsepower_breakdown (float | None), speed (PumpSpeed enum), amperage_max (float | None), frame (str | None), voltage (int = 240), part_number (PartReference | None = None).
    2. **JetPumpSpecs** (container): pumps (list[JetPumpSpec], Field(min_length=1, max_length=4)), diverter_valves (int | None), total_brake_horsepower (float | None), shared_with_series (bool = False).
    3. **CirculationPumpSpec**: model_name (str | None), description (str | None), is_dedicated (bool = True), wattage (float | None), part_number (PartReference | None), shared_with_series (bool = False).
    4. **SpaPakSpec**: model_name (str), display_type (str | None), voltage (int = 240), amperage (int | None), frequency_hz (int = 60), features (list[str], default_factory=list), part_number (PartReference | None), shared_with_series (bool = False).
    5. **TopsideControlSpec**: model_name (str | None), type (str | None), features (list[str], default_factory=list), smart_connectivity (str | None), part_number (PartReference | None), shared_with_series (bool = False).
    6. **JetTypeEntry** (single jet type): jet_type (str), quantity (int, Field(ge=0)), zone (str | None), part_number (PartReference | None), description (str | None).
    7. **JetSpecs** (container): total_jet_count (int), jet_system_type (JetSystemType = JetSystemType.FIXED), jets_by_type (list[JetTypeEntry], default_factory=list), jetpak_count (int | None), jetpak_options (int | None), therapy_jet_count (int | None), max_jet_count (int | None), shared_with_series (bool = False).
    8. **HeadrestSpec** (single): type (str | None), quantity (int | None), part_number (PartReference | None), description (str | None).
    9. **HeadrestSpecs** (container): headrests (list[HeadrestSpec], default_factory=list), shared_with_series (bool = False).
    10. **FilterSpec** (single): system_name (str | None), filter_type (str | None), filtration_area_sqft (float | None), quantity (int | None), description (str | None), no_bypass (bool | None), part_number (PartReference | None).
    11. **FilterSpecs** (container): filters (list[FilterSpec], Field(min_length=1)), shared_with_series (bool = False).
    12. **HeaterSpec**: model_name (str | None), wattage (int | None), voltage (int = 240), material (str | None), part_number (PartReference | None), shared_with_series (bool = False).
    13. **LightSpec** (single): location (str), type (str), description (str | None), part_number (PartReference | None).
    14. **LightingSpecs** (container): lights (list[LightSpec], default_factory=list), water_feature (str | None), shared_with_series (bool = False).
    15. **CoverSpec**: model_name (str | None), thickness (str | None), material (str | None), features (list[str], default_factory=list), length_inches (float | None), width_inches (float | None), part_number (PartReference | None), shared_with_series (bool = False).

    Then the **SpaModel** (top-level):
    - Identity: manufacturer (Manufacturer enum), series (str), model_name (str), year (int), seating_capacity (int)
    - 10 Categories: jet_pumps (JetPumpSpecs), circulation_pump (CirculationPumpSpec | None = None), spa_pak (SpaPakSpec), topside_control (TopsideControlSpec), jets (JetSpecs), headrests (HeadrestSpecs), filters (FilterSpecs), heater (HeaterSpec), lighting (LightingSpecs), cover (CoverSpec)
    - Physical: dimensions (DimensionsSpec)
    - Electrical: voltage (int = 240), amperage (int | None = None), requires_gfci (bool = True)
    - Metadata: compatibility_notes (list[str], default_factory=list), source_documents (list[SourceReference], default_factory=list)
    - Add model_config = ConfigDict(json_schema_extra={"description": "Canonical spa model specification for Dex knowledge system"})

    Add Field(description=...) annotations on key fields for JSON Schema documentation quality. At minimum: SpaModel.manufacturer, SpaModel.model_name, JetPumpSpec.position, JetPumpSpec.horsepower_continuous, JetSpecs.total_jet_count, PartReference.part_number.

    Update `backend/src/schema/__init__.py` to import and re-export SpaModel and all category models that downstream consumers need (SpaModel is the critical one, but also export PartReference, Manufacturer, and the category models for direct use in tests and MCP tools).

    Ensure pydantic is installed: run `cd backend && uv init --no-readme && uv add pydantic` if pyproject.toml does not exist yet. If uv is not available, use `pip install pydantic`.
